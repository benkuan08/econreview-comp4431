# PolyU emblem

The PolyU emblem is used at the user's request for this COMP4431 student project. Its shape is retained as a locally served SVG, extracted from the vector asset at:

https://raw.githubusercontent.com/quxiaofeng/PolyU_beamer_theme/master/themes/outer/polyu/polyulogo.pdf

The source is a public, unofficial PolyU presentation theme. The university's identity reference is https://www.polyu.edu.hk/about-polyu/university-identity/. Direct downloading from the university's server was unavailable during development. The logo is a university mark and is not claimed as original project artwork.

The interface uses the white emblem on burgundy. It identifies the work as a COMP4431 course project.
